## 0. 先定义“学会”和“精通”

| 等级 | 能力表现 | 对应阶段 |
| --- | --- | --- |
| L0 能跑 | 会保存、编译、运行一个最小程序，能看懂第一条报错 | 第 1 章 |
| L1 会写 | 掌握变量、分支、循环、函数、数组、字符串，能写几百行单文件程序 | 第 1-6 章 |
| L2 懂机制 | 理解地址、指针、动态内存、数据布局，能解释程序为什么崩溃 | 第 7-9 章 |
| L3 能持久化 | 会文件读写、错误处理、命令行参数、预处理和多文件构建 | 第 10-11 章 |
| L4 能交付 | 能拆需求、设计数据结构、处理失败路径、写测试并完成项目 | 第 12 章及项目 |
| L5 工程化 | 会调试、性能分析、内存检查、接口设计、代码审查、跨平台 | 本文第 6-8 节 |
| L6 语言专家 | 熟悉标准细节、ABI、优化、并发、系统接口和未定义行为边界 | 长期实践 |

**精通不是“语法都见过”**，而是能同时做到：

1. 写出的代码在正常、边界、错误输入下都正确；
2. 能解释内存里发生了什么；
3. 能定位编译期、链接期、运行期、逻辑期四类问题；
4. 能把大问题拆成职责清晰的函数和模块；
5. 知道自己的代码在哪些条件下是未定义行为。

## 2. 语法全景清单

### 2.1 翻译单元与程序结构

- 源文件到程序：预处理 → 编译 → 汇编 → 链接。
- 翻译单元（translation unit）：一个 `.c` 文件加上它展开后的所有头文件。
- `main` 的合法形式：`int main(void)`、`int main(int argc, char *argv[])`，以及实现定义的等价形式。
- 声明（declaration）与定义（definition）的区别：声明可以重复，定义通常只有一次。
- 头文件放接口：类型、宏、函数原型、`extern` 变量声明；`.c` 放实现。
- 包含守卫：

```c
#ifndef PROJECT_FILE_H
#define PROJECT_FILE_H
/* declarations */
#endif
```

- 链接属性：`static`（内部链接）、`extern` / 默认（外部链接）、无链接（局部变量）。
- 程序退出：`return`、`exit`、`_Exit`、`abort`；`0` 表示成功，非 0 表示失败。
- 标准输入/输出/错误：`stdin/stdout/stderr`。

### 2.2 词法元素

- 标识符：字母、数字、下划线；不能以数字开头；区分大小写；避开关键字。
- 关键字（C11 常见集合）：`auto break case char const continue default do double else enum extern float for goto if inline int long register restrict return short signed sizeof static struct switch typedef union unsigned void volatile while _Alignas _Alignof _Atomic _Bool _Complex _Generic _Imaginary _Noreturn _Static_assert _Thread_local`。
- 字面量：
  - 整数字面量：十进制、八进制（`0` 开头）、十六进制（`0x`）；后缀 `u/U`、`l/L`、`ll/LL`。
  - 浮点字面量：小数、指数、后缀 `f/F`、`l/L`；默认类型是 `double`。
  - 字符常量：`'A'`、`'\n'`、`'\x41'`、`'\101'`；类型是 `int`。
  - 字符串字面量：`"hello"`，以 `'\0'` 结尾；不可修改。
  - 转义序列：`\n \t \r \\ \' \" \0 \xNN \NNN`。
- 注释：`//` 到行尾；`/* ... */` 可跨行但不能嵌套。
- 分号结束表达式语句和声明；花括号构成复合语句和初始化列表。
- 全角标点不是 C 语法的一部分，是最常见的“看不见”错误之一。

### 2.3 类型系统

基本类型：

- 整数：`char`、`signed char`、`unsigned char`、`short`、`unsigned short`、`int`、`unsigned int`、`long`、`unsigned long`、`long long`、`unsigned long long`。
- 浮点：`float`、`double`、`long double`。
- 布尔：C99 的 `_Bool`，包含 `<stdbool.h>` 后可使用 `bool/true/false`。
- 空类型：`void`。
- 可选：`_Complex`、`_Imaginary`（实现可选，本教程不展开）。

派生类型：

- 数组、指针、函数类型、结构体、联合、枚举。
- 限定类型：`const`、`volatile`、`restrict`、`_Atomic`。

类型转换：

- 整数提升：小整数在表达式中通常提升为 `int`。
- 常用算术转换：不同整数类型或整数与浮点混合时，向“能表示更广”的类型转换。
- 显式转换：`(double)count / total`。
- 危险转换：`double → int`（丢小数）、大整数 → 小整数（实现定义/截断）、负数 → 无符号（按模回绕）。
- 有符号整数溢出是未定义行为；无符号整数溢出按模回绕。

`sizeof`：

- 结果类型是 `size_t`；单位是字节（`char` 固定为 1 字节，但不保证 8 位）。
- 数组在可见作用域内 `sizeof` 得总字节数；作为函数参数后退化为指针。
- 结构体大小包含填充；`offsetof` 可查成员偏移。

### 2.4 声明、初始化与存储期

- 声明语法：声明说明符 + 声明符 + 初始化器。
- 初始化 vs 赋值：初始化发生在对象创建时；赋值是之后改写。
- 局部自动变量不会自动清零，必须初始化。
- 全局变量和 `static` 变量默认初始化为 0。
- 存储期：自动（栈）、静态（全局/`static`）、动态（堆）、线程（`_Thread_local`）。
- `auto`：局部变量默认存储类，几乎总被省略。
- `register`：只是优化提示，不能取地址（现代代码很少使用）。
- `const`：对象只读；不是编译期常量（C 中不能用于数组长度，除非 VLA）。
- `volatile`：告诉编译器该对象可能被程序之外的因素改变，禁止过度优化；不用于线程同步。
- `restrict`：程序员承诺指针是访问对象的唯一途径，帮助优化；违反承诺是未定义行为。
- `_Atomic`：C11 原子类型；并发章节内容。
- `inline`：函数内联建议，链接语义比普通函数复杂。
- `_Noreturn`：函数不会返回（如 `exit`、`abort`）。
- `_Alignas` / `_Alignof`：指定/查询对齐。

### 2.5 表达式与运算符

按优先级从高到低（常用部分）：

1. 后缀：`() [] . -> ++ --`（复合字面量等略）
2. 前缀：`++ -- + - ! ~ * & sizeof _Alignof`、强制类型转换
3. 乘除：`* / %`
4. 加减：`+ -`
5. 移位：`<< >>`
6. 关系：`< <= > >=`
7. 相等：`== !=`
8. 按位与：`&`
9. 按位异或：`^`
10. 按位或：`|`
11. 逻辑与：`&&`
12. 逻辑或：`||`
13. 条件：`?:`
14. 赋值：`= += -= *= /= %= <<= >>= &= ^= |=`
15. 逗号：`,`

易错点：

- `=` 与 `==`；`&` 与 `&&`；`|` 与 `||`。
- `&` 的优先级低于 `==`：`flags & MASK == 0` 会先算 `MASK == 0`。
- `*p++`：先取 `*p`，再让 `p` 自增；`(*p)++` 是目标值自增。
- 不要让同一个变量在同一条表达式中被多次修改（如 `i++ + i++`），除非有明确顺序。
- 逻辑与/或短路：左侧能决定结果时，右侧不执行；不要把有副作用的代码依赖在短路里。
- 整数除法向零截断；负数取余符号由实现/标准规则决定，读标准或避免负数取余。
- 移位位数必须小于类型宽度；左移负数或有符号溢出是未定义行为；负数右移由实现定义。
- 浮点数不能用 `==` 直接比较，通常用容差 `fabs(a-b) < epsilon`。
- 三目运算符两分支类型会做常用算术转换，可能产生意外精度。

### 2.6 语句与控制流

- 复合语句：`{ ... }`。
- 表达式语句：`expr;`。
- 选择：`if`、`if/else`、`switch`。
- 循环：`while`、`do-while`、`for`。
- 跳转：`break`、`continue`、`return`、`goto`。
- 标号语句：`label:`（`goto` 的目标）。
- `switch` 的 `case` 必须是整数常量表达式；`default` 可选；忘记 `break` 会贯穿。
- 循环三要素：初值、终止条件、更新；写完后检查“第一次、最后一次、结束后”。
- 浮点循环变量容易累积误差，优先用整数计数器。
- `do-while` 至少执行一次，适合“先执行再询问是否继续”的菜单。
- `goto` 在 C 中常用于统一清理（如多条错误路径释放资源），不应滥用于普通流程。

### 2.7 函数

- 函数定义：返回类型、函数名、参数列表、函数体。
- 函数原型：让编译器检查调用；参数名可省略。
- 值传递：C 只有值传递；传指针是“传地址的值”，从而能修改目标对象。
- 数组参数：退化为指向首元素的指针，必须额外传长度。
- 函数返回：
  - 非 `void` 函数必须在所有路径返回值；漏掉是未定义行为（`main` 例外）。
  - 不能返回局部自动变量的地址。
  - 可以返回动态内存地址，但调用者负责释放。
- 递归：终止条件 + 规模缩小；注意栈深度和重复子问题。
- 可变参数：`<stdarg.h>` 的 `va_list/va_start/va_arg/va_end`；需要至少一个固定参数和明确格式。
- 函数指针：`int (*fp)(int, int);`；可用于回调、分发表、策略选择。
- 函数声明阅读法：从标识符开始，先看括号结合，再读“指针/数组/函数”。

### 2.8 数组与字符串

- 一维数组：`int a[N];`；下标 `0..N-1`。
- 初始化：`int a[5] = {1,2};` 剩余元素为 0；`int a[] = {...}` 自动确定长度。
- 二维数组：`int m[R][C];`；行优先连续存储；`m[i][j]`。
- 数组名在表达式中通常转换为首元素地址；`a[i] == *(a+i)`。
- `sizeof(a)` 与函数参数中的 `sizeof` 不同：后者得到指针大小。
- 变长数组（VLA）：C99 可选特性，长度在运行时确定；C11 起为可选，不建议在跨平台项目依赖。
- 字符串是以 `'\0'` 结尾的 `char` 数组。
- `char *s = "abc";` 指向字符串字面量，不能写；要修改用 `char s[] = "abc";`。
- 安全输入：`fgets(buffer, size, stdin)`；删除行尾 `\n`；超长输入清空剩余部分。
- 常用函数：`strlen`、`strcmp`、`strncmp`、`strcpy`、`strncpy`、`strcat`、`strncat`、`strchr`、`strrchr`、`strstr`、`memset`、`memcpy`、`memmove`、`snprintf`。
- 任何写操作先问：目标缓冲区有多大？源字符串有结束符吗？
- 宽字符/多字节：`<wchar.h>`、`<locale.h>`、`mbrtowc/wcrtomb`；UTF-8 和中文处理需要单独学习。

### 2.9 指针

- 指针保存地址；类型决定解引用时读取的宽度和解释方式。
- `&` 取地址；`*` 解引用；`NULL` 表示空指针；`nullptr` 是 C23 的写法之一（C 中通常仍用 `NULL`）。
- 指针初始化：`int *p = &x;` 或 `int *p = NULL;`；未初始化指针是野指针。
- 指针运算：`p + n` 按元素大小移动；仅在同一数组（或尾后）内有定义。
- 指针相减：结果类型 `ptrdiff_t`，表示元素个数差。
- 指针与数组：数组名可退化为首元素指针；指针不是数组，`sizeof` 不同。
- 指针的指针：`int **pp`；用于修改头指针、二维动态数组、输出参数。
- 指向数组的指针：`int (*p)[3]`；`p+1` 跨越一整行。
- 指针数组：`int *p[3]`；元素是指针。
- 指向函数的指针：`int (*fp)(int)`；`fp = func; fp(3);`。
- `void *`：通用对象指针；不能直接解引用；可隐式与其他对象指针互转（C 中）。
- `const` 位置：
  - `const int *p`：指向常量的指针，不能改 `*p`。
  - `int *const p`：常量指针，不能改 `p` 的指向。
  - `const int *const p`：两者都不能改。
- 返回值/生命周期：不要返回局部变量地址；不要解引用已 `free` 的指针；不要越界。
- 严格别名：通过不兼容类型指针访问对象可能违反严格别名规则；用 `memcpy` 或字符类型查看字节更安全。

### 2.10 结构体、联合、枚举与位域

- 结构体：`struct Name { ... };`；`typedef` 起别名。
- 初始化：`Student s = {1001, "Alice", 90.0};`；C99 指定初始化：`{.id = 1001, .score = 90.0}`。
- 访问：对象用 `.`，指针用 `->`。
- 结构体赋值：逐成员复制；含数组也能整体复制。
- 传参：值传递复制整个结构体；大结构体优先 `const Student *`。
- 返回结构体：合法，但可能涉及复制；小结构体通常没问题。
- 对齐与填充：成员之间可能插入字节；`sizeof(struct)` 可能大于成员之和；调整成员顺序可减少填充。
- 柔性数组成员：`struct S { size_t n; int data[]; };`（C99），需手动分配额外空间。
- 联合：成员共享存储；大小至少为最大成员；只能安全读取最近写入的成员（带标签联合可管理）。
- 枚举：命名的整数常量；底层类型由实现决定；不要依赖具体宽度。
- 位域：`unsigned flags : 3;`；布局由实现决定，不适合直接映射外部协议。
- 匿名结构体/联合：C11 支持；可简化嵌套访问，但可读性要权衡。

### 2.11 动态内存

- 生命周期：`malloc/calloc/realloc` 成功到 `free` 为止。
- `malloc(n)`：申请 n 字节，未初始化；`calloc(count, size)`：清零；`realloc(ptr, new_size)`：调整，可能搬移。
- 检查返回值：失败返回 `NULL`。
- 容量计算：`count * sizeof *p`，注意乘法溢出（`size_t` 溢出）。
- `realloc` 正确写法：

```c
void *tmp = realloc(p, new_size);
if (tmp != NULL) {
    p = tmp;
} else {
    /* p 仍然有效，需要另行处理 */
}
```

- `free(NULL)` 是安全的；`free` 非堆地址、重复释放是未定义行为。
- `free` 后置空指针，防止悬空引用。
- 泄漏、悬空、越界、双重释放是四类常见错误。
- 谁申请谁释放；接口要写清楚所有权转移规则。
- 内存池、arena、对齐分配、自定义分配器属于进阶主题。

### 2.12 文件与 I/O

- 流：`stdin/stdout/stderr`；`FILE *` 句柄。
- 打开模式：`r/w/a`、`r+/w+/a+`，加 `b` 表示二进制。
- 文本模式可能转换换行（Windows `\n` ↔ `\r\n`）；二进制模式按原始字节。
- 按行：`fgets`；按块：`fread/fwrite`；格式化：`fprintf/fscanf`；字符：`fgetc/fputc`。
- 定位：`fseek`、`ftell`、`rewind`；`ftell` 返回 `long`。
- EOF 与错误：`feof` 只在尝试读取到末尾后为真；`ferror` 检查错误；`clearerr` 清除状态。
- 关闭：`fclose` 会刷新缓冲区；必须检查返回值。
- 错误诊断：`errno`、`strerror(errno)`、`perror("...")`。
- 路径：相对路径相对于当前工作目录；文件名大小写和分隔符与平台有关。
- 二进制可移植性：不要直接 `fwrite` 结构体；按固定宽度、固定字节序逐字段编码。
- 安全：避免路径拼接溢出、TOCTOU、符号链接攻击；生产代码需专门设计。

### 2.13 预处理器

- 指令：`#include`、`#define`、`#undef`、`#if/#ifdef/#ifndef/#elif/#else/#endif`、`#error`、`#pragma`、`#line`。
- 对象宏：`#define PI 3.14159`。
- 函数式宏：每个参数和整体都要加括号；注意多次求值。
- 字符串化 `#`、记号粘贴 `##`、变参宏 `__VA_ARGS__`。
- 条件编译用于平台差异、调试开关、特性检测；不要用宏制造难以追踪的控制流。
- 包含守卫/`#pragma once`（后者非标准但常见）。
- 预定义宏：`__FILE__`、`__LINE__`、`__func__`（C99）、`__STDC__`、`__STDC_VERSION__`。
- 宏没有类型检查、没有作用域；能用 `const`、`enum`、`static inline` 就优先用它们。
- 编译期断言：C11 `_Static_assert(expr, "message");`。

### 2.14 标准库地图

- `<stdio.h>`：输入输出、文件。
- `<stdlib.h>`：内存、转换、随机数、排序、退出。
- `<string.h>`：字符串和内存块。
- `<ctype.h>`：字符分类与大小写转换（参数转 `unsigned char`）。
- `<math.h>`：数学函数、`NAN`、`INFINITY`、`isfinite`。
- `<limits.h>` / `<float.h>`：范围与精度。
- `<stdint.h>` / `<inttypes.h>`：固定宽度整数、格式宏。
- `<stdbool.h>`：布尔。
- `<stddef.h>`：`size_t`、`ptrdiff_t`、`offsetof`、`NULL`。
- `<time.h>`：时间、`clock`。
- `<errno.h>`：错误码。
- `<assert.h>`：断言。
- `<stdarg.h>`：变参。
- `<stdatomic.h>` / `<threads.h>`：C11 原子与线程（实现支持情况需检查）。
- `<signal.h>`、`<setjmp.h>`、`<locale.h>`、`<wchar.h>`：进阶/专用。

### 2.15 未定义行为、未指定行为、实现定义行为

- **未定义行为（UB）**：标准不规定结果，编译器可以做任何事，包括“看起来正常”。
- **未指定行为**：标准给出若干可能，但不要求选哪个（如函数参数求值顺序）。
- **实现定义行为**：实现必须文档化选择（如 `char` 是否有符号、右移负数）。

常见 UB：

1. 有符号整数溢出；
2. 数组越界访问（包括读写、指针解引用）；
3. 解引用空指针/野指针；
4. 使用未初始化局部变量；
5. `free` 后继续使用、重复 `free`；
6. `free` 非 `malloc` 系列返回的地址；
7. 除零/模零；
8. 移位位数大于等于类型宽度；
9. 左移负数或左移导致有符号溢出；
10. 修改字符串字面量；
11. 非 `void` 函数漏返回值（调用者使用返回值时）；
12. 格式串与参数类型不匹配；
13. 同一表达式中对同一对象多次无序修改；
14. 通过不兼容类型指针访问对象（严格别名）；
15. 指针运算越出同一数组范围（尾后一位可以，但不能解引用）；
16. `realloc` 后继续使用旧指针；
17. 变参函数读取的类型与传入不一致；
18. `memcpy` 重叠区域（应使用 `memmove`）；
19. 对齐不正确的指针解引用；
20. 返回局部变量地址并解引用。

> 关键态度：不要用“我的机器上没崩”证明代码正确。开启警告、消毒器、测试边界，才是证据。

### C 标准版本速览

- **C89/C90**：经典基础；变量声明必须在块开头，无 `//` 注释。
- **C99**：`//` 注释、`for` 内声明、变长数组、`stdint.h`、指定初始化、`inline`、`restrict`、`snprintf`、变参宏。
- **C11**：`_Generic`、`_Static_assert`、`_Atomic`、线程库（可选）、匿名结构/联合、对齐控制、`gets` 被移除。
- **C17/C18**：主要是缺陷修复，无大语法变化。
- **C23**：`nullptr`、`typeof`、`constexpr`（C 风格）、位精确整数、属性、`#embed` 等；编译器支持程度需确认。

本教程以 C11 为基线，避免依赖编译器扩展。

## 7. 工具链速查

```bash
# 严格编译
gcc -std=c11 -Wall -Wextra -Wpedantic -Werror -Iinclude src/*.c -o app -lm

# 调试符号
gcc -std=c11 -g -O0 ...

# AddressSanitizer（GCC/Clang）
gcc -std=c11 -g -fsanitize=address,undefined ...

# 只看预处理结果
gcc -E src/main.c -Iinclude

# 生成汇编
gcc -S -O2 src/main.c

# 只编译不链接
gcc -std=c11 -Iinclude -c src/main.c -o build/main.o

# 用 GDB 调试
gdb ./app
# break main / run / next / step / print x / backtrace / quit

# 用 Valgrind（Linux）
valgrind --leak-check=full ./app
```

Windows 下可用 WinDbg、Visual Studio 调试器或 `gdb`（MinGW 附带）。核心方法一致：断点、单步、观察变量、看调用栈。
