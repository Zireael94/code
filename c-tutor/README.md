# C 语言阶梯教程（c-tutor）

一个可以直接运行的中文命令行 C 语言教程。它不是静态讲义，而是把 **讲解、可运行案例、随堂小测、课后作业、学习进度和综合项目** 放进同一个程序里。

- **12 章 · 4 个阶段**：从第一个 `printf` 到能读写文件、管理内存、拆解多文件项目。
- **38 个实操案例**：成绩统计、四则计算器、猜数字、汉诺塔、排序查找、回文、凯撒密码、链表、文件、位运算、学生成绩管理系统等。
- **34 道随堂小测 · 60 道课后作业**：每题都有验收标准，作业同时写在每个 `.c` 文件末尾的注释里。
- **每行 C 代码都有行注释**：共 15 个 `.c/.h` 文件、3300+ 个非空行，可用脚本逐行验证。
- **学习进度自动保存**：完成一章后写入 `progress.txt`，下次启动继续。
- **最终项目可直接使用**：学生成绩管理系统支持增删改查、排序、统计和 CSV 持久化。

## 1. 立即运行

### Windows（推荐）

项目里已经带了构建好的 `c_tutor.exe`，可以直接：

```text
双击 run.bat
```

或在 PowerShell / cmd 中：

```bat
cd /d G:\code\c-tutor
.\c_tutor.exe
```

需要重新编译时：

```bat
build.bat
```

`build.bat` 使用 MinGW-w64 的 `gcc`，开启 `-Wall -Wextra -Wpedantic` 并静态链接运行时，生成 `c_tutor.exe`。

### Linux / macOS

```bash
cd c-tutor
make
./c_tutor
```

`Makefile` 使用 `gcc` 和 C11 标准；Windows 下请使用 `mingw32-make`。

### 手动编译命令

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -O2 -g \
    -finput-charset=UTF-8 -fexec-charset=UTF-8 \
    -Iinclude src/*.c -o c_tutor.exe -lm
```

要求：

- 支持 C11 的 GCC 或 Clang（本项目在 MinGW-w64 GCC 8.1 上验证通过）。
- 终端使用 UTF-8 编码；程序在 Windows 启动时会自动把控制台切到 UTF-8。
- 不需要任何第三方库。

## 2. 怎么使用这个程序

启动后进入主菜单：

```text
[ 1] 基础篇 程序结构、编译流程与输入输出
...
[12] 实战篇 学生成绩管理系统
[13] 查看学习路线
[14] 重置进度
[ 0] 退出
```

输入章节编号即可学习。每章按固定节奏推进：

1. **本章目标**：先知道要掌握什么。
2. **知识讲解**：核心概念、语法规则和常见坑。
3. **运行案例**：真实输入、真实计算、真实输出。
4. **本章小测**：3 道选择题（第 1、12 章为 2 道），立即判定并解释。
5. **课后作业**：屏幕上列出任务，源码末尾也有同样内容的注释。
6. **完成记录**：正常结束后自动保存进度。

随时按 `Enter` 继续；输入流结束（例如重定向输入读完）时程序会安全退出，不会死循环。

### 命令行参数

```text
c_tutor.exe --list          列出全部章节
c_tutor.exe --chapter 3     直接进入第 3 章
c_tutor.exe --version       显示版本
c_tutor.exe --help          帮助
```

`--chapter N` 适合复习单章；完成后同样会记录进度。

### 会生成哪些文件

文件都写在**程序当前工作目录**：

| 文件 | 用途 |
| --- | --- |
| `progress.txt` | 已完成的章节编号，一行一个 |
| `students.csv` | 第 12 章综合项目的学生数据 |
| `demo_scores.txt` | 第 10 章文本文件案例生成 |
| `demo_scores.dat` | 第 10 章二进制文件案例生成 |
| `study.log` | 第 10 章追加日志案例生成 |

这些文件都可以安全删除。想从头开始：删除 `progress.txt`，或使用主菜单 `[14] 重置进度`。

## 5. 推荐学习节奏

### 每章五步法

1. 先读“本章目标”和“知识讲解”，把不确定的点记下来。
2. 运行全部案例，故意输入边界值和非法值，观察程序反应。
3. 做小测；错题回到对应小节重读。
4. **关掉程序**，只看作业要求独立写代码。
5. 编译时开 `-Wall -Wextra -Wpedantic`，做到零警告，再用边界数据测试。

### 四周计划

| 周 | 内容 | 目标 |
| --- | --- | --- |
| 第 1 周 | 第 1-3 章 | 能写带输入、判断、循环的小程序；能读懂编译错误 |
| 第 2 周 | 第 4-6 章 | 会用函数、数组、字符串组织几百行程序 |
| 第 3 周 | 第 7-9 章 | 理解地址和内存；能管理动态数据；会定义复合类型 |
| 第 4 周 | 第 10-12 章 | 会文件持久化；能完成并测试一个多文件项目 |

如果每天只有 1 小时，可以按“两天一章”推进，但第 7、8、12 章建议各留出两天以上。

## 6. “每行注释”和“案例后作业”是怎么落实的

### 每行代码都有注释

所有 `.c` / `.h` 文件都遵守同一约定：**每个非空行都带 `//` 注释**。例如：

```c
int score = 0; // 保存百分制成绩
if (score >= 90) { // 90 分及以上为 A
    level = 'A'; // 记录 A 等级
} // 等级判断结束
```

这不是只注释“关键行”，而是连声明、循环、`break`、右花括号都解释“这一行在做什么、为什么”。

自动检查：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/check_comments.ps1
# 或
mingw32-make check
```

检查脚本会识别字符串内的 `//`，只把真正的行注释计入，避免“字符串里恰好有斜杠”造成误判。

### 案例后用注释布置作业

每个章节文件在**所有案例函数之后**都有一段完整的作业注释块，包含任务、提示、验收标准和提交标准。例如第 1 章末尾：

```c
// ============================================================================
// 第 1 章课后作业（与程序内显示的作业一致，可直接在源码中边改边练）
// 1. 改写 Hello 程序：输出 5 行个人信息，至少使用 \n、\t 和转义引号。
//    验收：编译无警告；运行后每行内容完整，引号与反斜杠显示正确。
// ...
// ============================================================================
```

程序运行时也会用 `ui_homework()` 在屏幕上展示同样的任务，所以不必一边翻源码一边看屏幕。作业强调**可验收**：输入范围、边界数据、错误路径、需要解释的概念都写清楚了。

## 7. 综合项目：学生成绩管理系统

第 12 章是一个完整的小型管理系统，而不是伪代码：

- 学生字段：学号、姓名、语文、数学、英语、总分、平均分。
- 功能：查看、添加、按学号查找、修改、删除、按总分排序、班级统计、保存、重新加载。
- 学号唯一，成绩范围 0-100，姓名不能含逗号（避免破坏 CSV）。
- 修改时先改副本，输入失败不破坏原记录。
- 删除有二次确认，删除后移动数组并清理残留。
- 退出时若有未保存修改，会询问是否保存。
- CSV 文件可直接用记事本查看：

```csv
# id,name,chinese,math,english
1001,林小满,88.5,92.0,90.0
```

### 推荐体验流程

1. 添加 2-3 名学生。
2. 查找一个不存在的学号，观察失败提示。
3. 修改其中一名学生的成绩，再排序、看统计。
4. 保存，退出程序。
5. 重新运行，选择“从文件加载”，确认数据仍在。
6. 删除中间一条记录，再保存、加载，验证顺序正确。

## 9. 设计取舍与扩展方向

- **固定容量 100 人**：综合项目先用数组把增删改查讲透；动态扩容作为第一道项目作业。
- **文本 CSV 而非二进制**：便于学习者用记事本检查数据；二进制读写已在第 10 章单独演示。
- **UTF-8 控制台**：Windows 下通过 `SetConsoleOutputCP(CP_UTF8)` 设置；如果终端字体不支持中文，请换 Windows Terminal 或等宽中文字体。
- **单目录数据文件**：所有文件写在当前工作目录，方便携带；生产项目应使用明确的配置目录。
- **无第三方依赖**：只用 C 标准库和少量 Windows API，便于在任意 MinGW 环境复现。

## 10. 从“学完”到“精通”

完成 12 章只代表掌握了 C 的核心语法和基本工程能力。继续深入建议按这个顺序：

1. **算法与数据结构**：复杂度分析、动态数组、栈/队列、哈希表、树、图。
2. **内存与调试**：AddressSanitizer、Valgrind、GDB/WinDbg、未定义行为、内存布局。
3. **系统编程**：POSIX / Win32 文件与进程、网络、线程、同步、原子操作。
4. **工程能力**：多文件架构、接口设计、单元测试、代码审查、版本控制、性能分析。
5. **语言深度**：C11/C17/C23 新特性、`restrict/volatile/_Atomic`、变参函数、ABI、编译器扩展。
6. **阅读源码**：从一个小型开源 C 项目开始，沿着 `main → 接口 → 数据结构 → 错误路径` 读。

更细的清单、UB 列表和 30 天计划见 [docs/C语言知识地图.md](docs/C语言知识地图.md)。

## 11. 常见问题

**中文显示乱码？**  
程序会主动把 Windows 控制台切到 UTF-8。若仍乱码，使用 Windows Terminal，或在“属性 → 字体”中选择支持中文的等宽字体。不要把源码另存为 GBK。

**提示找不到 gcc？**  
安装 MinGW-w64，把 `...\mingw64\bin` 加入 `PATH`，重新打开终端，运行 `gcc --version` 验证。

**进度无法保存？**  
程序需要当前目录可写。把项目复制到用户目录（例如 `D:\c-tutor`）再运行，避免放在 `C:\Program Files` 等受保护位置。

**如何重置综合项目数据？**  
删除 `students.csv`。加载器会跳过损坏行并报告数量；删除后从空数据库开始。

**作业有标准答案吗？**  
没有直接附答案。每道题都给出了验收标准和提示；建议先独立完成，再用小测和边界测试验证。需要时可以把你的实现发回来一起 review。

**可以修改章节或增加第 13 章吗？**  
可以。新增 `src/ch13_xxx.c`，在 `include/tutor.h` 声明 `lesson_13_xxx`，在 `src/main.c` 的 `g_chapters[]` 加一行、把 `CHAPTER_COUNT` 改为 13，然后重新构建。记得继续遵守每行注释约定。
