# C 语言阶梯教程

从第一条 `printf`，到能读写文件、管理内存、拆解多文件项目的 C 语言学习仓库。

本项目不是静态课件，而是一个可直接在终端运行的**交互式 C 语言教程**：每章包含知识讲解、可操作案例、随堂小测和课后作业，最后一章完成一个学生成绩管理系统。

---

## 项目亮点

| 规模 | 内容 |
| --- | --- |
| 12 章 | 基础、进阶、深入、实战四个阶段 |
| 38 个案例 | 计算器、猜数字、汉诺塔、排序查找、链表、文件、位运算等 |
| 34 道小测 | 即答即判，附带解析 |
| 60 道作业 | 每题有提示和验收标准，写在源码案例之后 |
| 15 个 C/H 文件 | 每一个非空 C 代码行都有注释 |
| 1 个完整项目 | 学生成绩管理系统，支持 CSV 持久化 |

其他特点：

- **由浅入深**：从编译流程讲到指针、动态内存、文件和多文件工程。
- **真正可操作**：所有案例都能输入、计算、输出，不是伪代码。
- **严格检查**：在 `-Wall -Wextra -Wpedantic -Werror` 下零警告构建。
- **自动记录进度**：完成章节后写入 `progress.txt`，下次继续。
- **配套完整文档**：[C 语言知识地图](c-tutor/docs/C语言知识地图.md) 收录语法全景、未定义行为清单和进阶路线。

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/Zireael94/code.git
cd code/c-tutor
```

### 2. Windows 构建运行

需要 MinGW-w64 的 `gcc`：

```bat
build.bat
run.bat
```

也可以直接执行：

```bat
.\c_tutor.exe
```

`build.bat` 会开启严格警告并静态链接，生成 `c_tutor.exe`。

### 3. Linux / macOS 构建运行

```bash
make
./c_tutor
```

### 4. 环境要求

- 支持 C11 的 GCC 或 Clang；
- Windows 下需要 MinGW-w64 或 Git for Windows 自带环境；
- 终端支持 UTF-8；程序启动时会自动设置 Windows 控制台代码页；
- 不需要任何第三方库。

## 每行注释与案例作业

所有 `c-tutor` 下的 `.c` / `.h` 文件都遵守同一约定：**每个非空行都带 `//` 注释**，包括声明、循环、`break` 和右花括号。

例如：

```c
int score = 0; // 保存百分制成绩
if (score >= 90) { // 90 分及以上为 A
    level = 'A'; // 记录 A 等级
} // 等级判断结束
```

每个章节文件在案例函数之后，都有一段作业注释块，包含任务、提示、验收标准和提交标准：

```c
// ============================================================================
// 第 1 章课后作业
// 1. 改写 Hello 程序：输出 5 行个人信息，至少使用 \n、\t 和转义引号。
//    验收：编译无警告；运行后每行内容完整，引号与反斜杠显示正确。
// ...
// ============================================================================
```

这一约定可以用脚本验证：

```powershell
cd c-tutor
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/check_comments.ps1
```

当前结果：

```text
[PASS] 已检查 15 个 C/H 文件、3342 个非空行，每行都包含 // 注释。
```

## 综合项目

第 12 章是一个可以直接操作的成绩管理系统：

- 添加、查看、查找、修改、删除学生；
- 按总分降序排序；
- 班级平均分、最高/最低总分、及格率、优秀率；

## 推荐学习方式

1. **先运行，再阅读**：直接进入第 1 章，观察程序如何编译、输入和输出。
2. **每章按顺序完成**：知识讲解 → 案例 → 小测 → 作业，不跳步。
3. **修改案例做实验**：故意输入 0、负数、超长文本和非法字符，观察错误处理。
4. **独立完成作业**：先不要看现成答案；用边界数据验证自己的实现。
5. **最后做综合项目**：先跑通，再扩展容量、模块化和测试。

四周节奏建议：

| 周 | 章节 | 目标 |
| --- | --- | --- |
| 第 1 周 | 1-3 | 能写带输入、分支、循环的小程序 |
| 第 2 周 | 4-6 | 会用函数、数组、字符串组织程序 |
| 第 3 周 | 7-9 | 理解指针、动态内存和复合类型 |
| 第 4 周 | 10-12 | 会文件持久化并完成综合项目 |
